# 用户端首页重整

日期：2026-10-15。长期用户端分支：`feature/requester-experience`。
该分支从 `feature/login-visual-refresh-20261015` 当前已提交状态创建，保留已完成的登录页及此前首页公告工作。
本轮集中调整普通用户 `/`、`/home`，后续用户端界面可继续使用该分支；管理员及工程师仍按原服务器角色规则跳转至自己的工作台。

## 页面规划

1. 顶部仅保留一个滑动横幅。第一张是原来的 Welcome back 与校园 PNG；后续为真实有效公告，复用原公告服务，最多六条，不添加示例公告。
2. 中间是等高双栏：左侧最近三条报修，右侧可直接打开的 Campus Map 卡片。“View all”进入完整报修列表。
3. 社区保留 Browse discussions、Ask a question 两个主要入口；My questions、My answers 改为同一模块标题栏中的次要入口。

删除独立的 Campus updates 空状态面板、整行地图推广条、From report to repair 纯说明面板和重复的大型“我的社区”入口卡片。没有公告时第二张展示真实的公告空状态，不制造公告内容。

## 视觉与交互

- 首页专用 `requester-home.css`，主标题 28–44px，主要正文 16–18px，模块标题 21–23px。桌面模块统一外边缘、24px 网格间距和头部内边距，手机缩减至18px间距。
- 保留现有校园 PNG。新增 `static/images/campus-notice.png`，由 imagegen 技能生成透明的深绿／奶油／金色公告板与扩音器插图，已复制进项目；不依赖生成目录或远程图片服务。地图卡片装饰是抽象 SVG，不代表真实建筑位置；实际地图仍通过现有 `/campus-map` 打开。
- 横幅支持上一张／下一张、分页圆点、原生触屏／触控板横向滚动和桌面鼠标拖动。聚焦横幅区域时支持左右键、Home、End。无公告也保留“欢迎＋公告空状态”两张和控制条。
- 不自动轮播。相邻切换平滑，跨多页及减少动态效果设置即时切换；调整窗口宽度后保留当前页。位置状态提供给辅助技术，按钮原生可聚焦。
- 欢迎插图只有一次轻微入场与鼠标跟随。减少动态效果时关闭；触屏不执行鼠标位移。所有导航均连接真实现有页面，无演示按钮或虚构统计。
- 报修使用现有 DTO 展示真实工单号、标题、位置、状态和新加坡时间；点击整行进入对应工单。首页只取当前用户最近三条，不改变完整报修列表、状态流转或数据权限。
- 无 JavaScript 时横幅仍可横向滚动，业务链接正常可用；标题、公告正文继续经过 Thymeleaf 转义。

## 轮播修正与顶部导航跟进

用户现场截图只出现欢迎页的原因已确认：上一版把控制条和后续页都绑定到非空公告列表，空数据没有实际可切换的页面。已修正为始终至少两页，第二页在无公告时明确显示 No current announcements，并保留真实公告列表入口。没有加入虚构公告。

鼠标拖动在超过阈值后才捕获指针并暂停 scroll-snap，释放时定位到目标页；不拦截链接和按钮的指针操作。触屏继续使用原生横向滚动，不妨碍纵向页面滚动。减少动态效果设置仍有效。

用户顶部导航在共享片段上添加 `appbar--requester`，只对 REQUESTER 加载 `requester-navigation.css`，因此首页、社区、报修、地图等用户页面保持同一导航风格，管理员和工程师不变。Home／Community／My Requests／Campus Map 加入装饰图标、分组背景、明确的当前页边框与底部标记。账户、密码、通知和退出有独立操作区域。移动端菜单采用两列，支持 Escape、点击外部关闭、ARIA 开关同步；改变为桌面宽度时重置展开状态。

此次相关页面与权限测试 **100 项通过**。浏览器检查 **143 项通过**，包括真实鼠标向左／向右拖动、CDP 触摸手势模拟、空公告页按钮、901px 桌面边界、手机菜单状态和外部关闭；截图经人工复核。浏览器环境仍是隔离渲染模板，不代表真机触屏验收。`mvn -o -DskipTests package` 成功，最终模板缓存版本调整也已重新打入本地包。

首页脚本和样式地址更新为 `v=20261015b`，新导航使用同版本号，避免普通刷新继续命中旧资源。启动／重启应用后，零公告首页也应显示 `1 / 2` 和可用的下一页按钮。

### 配色与顶部栏轻量调整

根据用户后续截图反馈，桌面顶部栏取消导航大底框、选中项卡片阴影和多余按钮边框，改为文本导航、轻量悬停和短下划线当前页标识；桌面隐藏装饰图标，手机菜单保留图标便于辨认。公告与欢迎页统一深绿、浅色正文和金色按钮，避免米色主体与深绿控制栏割裂。CSS 缓存版本更新为 `20261015c`，滑动和菜单逻辑保持不变。

随后按用户提供的 LinkedIn 导航排列参考，桌面改为上图标、下文字，每个入口最小宽度102px，间距20px；901–1200px收紧到88px入口和12px间距。沿用现有可缩放图标，保持清晰及统一配色，当前页仍用细下划线提示；手机保留两列菜单。导航缓存版本更新为 `20261015d`。

进一步根据顶部高度与中间留白反馈，桌面导航改成品牌／主导航／账号三组网格，主导航均分可用宽度，移除原 `margin-right:auto` 造成的大片空白。三组统一64px高度，并采用26px图标行＋20px文字行的共同节奏。右侧密码、退出、通知也使用上图标下文字，头像下展示用户名；品牌副标题与导航文字行对齐。901–1100px只压缩列宽与字号，手机菜单不变。缓存版本更新为 `20261015e`。
