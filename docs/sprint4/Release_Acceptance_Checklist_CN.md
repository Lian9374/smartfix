# 非 AWS 发布验收清单

负责人：UserA；各模块负责人提供自己的实现、测试和评审。更新日期：2026-10-13。

## 自动化门禁

- 编译与构建：`mvn -o -DskipTests compile` 和 `mvn -o -B verify`；检查失败、错误与跳过数。
- PostgreSQL：专用 `_test` 数据库上的 `mvn -o -B -Ppostgres-it verify`；覆盖空库／旧库迁移、并发派单／采纳和初始化约束。
- 社区真实浏览器：提问、编辑、回答、采纳、举报、隐藏、恢复、通知、审计、重启数据保留与服务器校验。
- 全角色真实浏览器：管理员创建工程师、首次改密码、配置技能／服务范围、普通用户提交、管理员审核／派单、维修记录、提交解决、用户确认、关闭。
- 管理页面与共享页面：账户、工程师、设施、报表、公告、通知和地图的 HTTP／布局检查。
- 无障碍自动检查：键盘跳到正文、单 h1、重复 ID、标签／说明关联、脚本错误、320/390/768/1000/1440px 宽度；对比度仅按实际抽样范围记录。
- JavaScript 语法及 `git diff --check`。

本轮实际状态与证据见 [UserA 发布验收](UserA_Release_Acceptance_CN.md)，不以本清单的文字存在视为已经通过。

## 必须人工／外部关闭的门禁

- [ ] 实际手机检查，注明设备、系统、浏览器和版本。
- [ ] 实际读屏路径，注明工具、版本、表单提示与焦点行为。
- [ ] B/C/D/E 评审和交接，不能以作者自测替代批准。
- [ ] SLA／邮件遗留完成，或正式的范围调整结论。
- [ ] 可靠通知失败／重启补发及附件故障一致性验收材料。
- [ ] 最终集成分支含迁移修复，发布 SHA／源码指纹与构建产物可追溯。

## 发布判断

编译、迁移、越权、关键链路失效或数据丢失属于阻塞。全部自动检查通过也不自动关闭人工／外部门禁。

AWS 部署完成与否不由本清单认证。全范围发布前还需云部署工作包单独验收。
