# 评分、消息角标、取消报修及详情排版

日期：2026-10-17
分支：feature/requester-detail-refresh

## 功能

- 评分改为五颗星的原生单选控件，鼠标、键盘方向键和辅助技术均可操作，提交值仍为 1–5。
- 反馈框全宽、至少 170px 高，支持多行、字数提示和原有后端校验。已有评分也用星星展示，反馈内容独立分隔。
- 所有登录角色的消息入口显示当前账号的真实未读数；0 隐藏，超过 99 显示 99+。读后重新渲染会更新数量，无跨账号计数。
- 请求者可在 SUBMITTED、UNDER_REVIEW、ASSIGNED 阶段取消自己的请求。已开工、已完成和其他终态不能取消。
- ASSIGNED → CANCELLED 同一事务关闭关联工单，保留指派和状态历史；工程师不得再次开始、记录或完成该工单，不再计入活跃工单。
- 取消提供可展开的说明、确认及成功提示。取消失败的并发写由现有乐观锁和工作状态校验处理。
- 管理员详情的操作信息使用分组网格，解决方案和评分反馈单独分隔；修正动态未读标签对导航布局的影响。
