## 页面结构

- 与首页共用内容宽度、深绿色、奶油白与柔金配色。
- 标题、编号和提交时间集中在顶部，右侧使用现有 engineer-dispatch.png，小屏隐藏装饰以优先显示内容。
- 当前状态与五阶段进度合并，直接说明下一步；取消/拒绝的请求不显示成功路径。
- 主列展示故障描述、维修更新和状态历史，右侧摘要保留地点、分类、紧急程度和更新时间，两列顶端对齐。
- 用户端不重复展示编号、状态、提交时间；隐藏内部工单 ID、重复工单状态、未填写的解决方案和空照片提示。
- 已填写的解决方案使用淡绿色内容块；返修原因使用原生可折叠入口，验证错误时展开。
- 保留真实权限和现有提交路由。验收、返修、评价和管理员终审业务逻辑未更改。
